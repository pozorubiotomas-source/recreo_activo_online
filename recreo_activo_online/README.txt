RECREO ACTIVO — VERSION ONLINE

1) Crea un proyecto en Supabase.
2) En Supabase > SQL Editor, pega TODO el contenido de supabase.sql y ejecútalo.
3) En Supabase > Connect, copia Project URL y Publishable key.
4) Abre index.html con un editor y reemplaza:
   PEGA_AQUI_TU_SUPABASE_URL
   PEGA_AQUI_TU_PUBLISHABLE_KEY
   Usa SOLO la publishable/anon key en el navegador. Nunca pongas service_role.
5) Sube index.html y logo.png a un hosting estático (por ejemplo Vercel, Netlify o GitHub Pages).
6) Abre la URL publicada y crea una cuenta.

La app permite registro, inicio de sesión, perfiles, crear actividades, ver participantes, unirse, salir y eliminar actividades propias. La base de datos usa RLS.
